# TikTok Remove All Likes

Panduan ini menjelaskan cara menghapus semua like di TikTok dengan mudah menggunakan ekstensi Chrome.

## Prasyarat

Sebelum memulai, pastikan Anda menggunakan browser Google Chrome.

## Langkah-langkah Instalasi

1. **Unduh dan Instal Ekstensi**:
   Buka tautan berikut dan tambahkan ekstensi ke Chrome:
   [TikTok Remove All Likes](https://chromewebstore.google.com/detail/eafmacjdgennnmhagdkdckgjokmnllci?utm_source=item-share-cp)

2. **Login ke TikTok**:
   - Buka situs web TikTok dan login ke akun Anda seperti biasa.

3. **Jalankan Ekstensi**:
   - Masuk ke bagian **Profil**.
   - Jalankan ekstensi yang telah diinstal.
   - Tunggu beberapa saat hingga proses selesai.

Dengan cara ini, semua like di TikTok akan dihapus secara otomatis.
